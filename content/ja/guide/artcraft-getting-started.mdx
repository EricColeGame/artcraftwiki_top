ArtCraftはAI画像と動画を生成するためのオープンソースのデスクトップアプリです。設定をプリセットの裏に隠してしまうブラウザツールに窮屈さを感じたことがあるなら、試してみる価値は十分にあります。このArtCraft入門ガイドでは、AIの事前知識がまったくないことを前提に、インストール、最初のプロンプト、参照画像、アニメーションまでを順を追って解説します。ArtCraftを始めるうえで肝心なのはただ一点、モデルに振り回されるのではなく、あなたがモデルを導くということです。

以下では、チェックリスト、手順表、プロンプトのフレームワーク、そしてほぼすべての新規ユーザーが最初の1週間でつまずく問題の解決策を紹介します。

## ArtCraftとは何か（そして誰のためのものか）

ArtCraftは、AI画像・動画生成のためのネイティブデスクトップアプリケーションで、意図的なコントロールを求めるアーティスト、デザイナー、映像制作者のために作られています。プロジェクトは自らを「意図的なクラフティングエンジン（intentional crafting engine）」と表現しており、これはその哲学をうまく言い表しています。つまり、あなたが選択し、結果を検証し、ファイルを自分のマシンに保存するのです。

ブラウザのタブではなくインストールされたアプリとして動作するため、参照画像、プロジェクト、レンダリング結果はすべて自分のフォルダに保存されます。アカウントアクセス用のWebコンパニオンも用意されていますが、実際の生成処理はデスクトップクライアントで行われます。プロジェクト自身の説明は[ArtCraft公式サイト](https://getartcraft.com/)で読めますし、[GitHubのオープンソースリポジトリ](https://github.com/storytold/artcraft)では、このエンジンが内部で何をしているのかを正確に確認できます。

| 項目 | ArtCraft（デスクトップ、オープンソース） | 一般的なブラウザ生成ツール |
|---|---|---|
| 動作環境 | インストール型デスクトップアプリ | ブラウザのタブ |
| ソースコード | 公開されておりコミュニティが検証可能 | 非公開 |
| プロンプト制御 | 詳細なモデルレベルの設定 | 簡略化されたプリセット |
| モデル対応 | 動画モデルを含む複数のモデルが順次追加 | 通常は固定の1モデル |
| ファイル管理 | レンダリング結果は自分のストレージに保存 | クラウドライブラリ |
| セットアップ | インストール1回＋モデルのダウンロード | 即時サインアップ |

誰に向いているのか？ コンセプトアーティスト、イラストレーター、モーションデザイナー、インディー映像作家、そして実験を楽しむホビイストです。誰に向いていないのか？ ボタン一つで完成した映画が出てくることを期待する人です。ArtCraftは反復作業に報いてくれます。それは欠点ではなく、利点です。

## ArtCraft入門：事前チェックリスト

ここで5分使えば、1時間のイライラを節約できます。初日のトラブルのほとんどは、ソフトウェア自体ではなく、準備が整っていないマシンに起因します。

| 確認項目 | 重要な理由 | 確認方法 |
|---|---|---|
| 対応OS | デスクトップ版はお使いのプラットフォームに一致する必要がある | 公式サイトのダウンロードページを確認する |
| GPUとビデオメモリ | 画像生成の負荷は控えめだが、動画生成はグラフィックスカードに大きく依存する | 公表されている要件と自分のGPUを比較する |
| 空きディスク容量 | モデルとレンダリング結果は大きなファイルになる | インストール前に余裕のある空き容量を確保する |
| 安定したインターネット接続 | 初回使用時にモデルがダウンロードされる | 有線接続または強力なWi-Fi |
| 参照画像フォルダ | 参照画像は言葉だけよりもはるかにうまくスタイルと構図を導いてくれる | 気に入った画像を5〜10枚集める |
| アカウント | Webコンパニオンと一部のクラウド機能に必要 | 公式アプリポータルから登録する |

コミュニティの報告から2点。インストールは必ず公式ソースから行ってください。サードパーティのミラーは古いビルドを配布している可能性があります。そして、動画に挑戦する前に画像生成から始めてください。動画レンダリングは格段に負荷が重く、最初のセッションを遅いレンダリング待ちに費やすのは最悪の第一印象になります。

## 最初のセッションを順を追って

ここがArtCraft入門の核心です。レシピのように扱ってください。一度この通りにやってみれば、インターフェースはもう他人事ではなくなります。

| # | ステップ | やること | 成功の目安 |
|---|---|---|---|
| 1 | ダウンロード | 公式サイトからデスクトップ版を入手する | インストーラーが問題なく起動する |
| 2 | インストール | インストーラーを実行し、必要なものを取得させる | アプリがワークスペースを開く |
| 3 | サインイン | 求められたらログインする | ワークスペースが正常に読み込まれる |
| 4 | 画像モデルを選ぶ | 動画から始めたい衝動をぐっとこらえる | モデルが選択され、準備完了になる |
| 5 | 最初のプロンプトを書く | 被写体1つ、スタイル1つ、ライティングの指定1つ | 出力パネルにプレビューが表示される |
| 6 | 反復する | 1回のレンダリングにつき変数を1つだけ変える | 各試行から具体的な学びが得られる |
| 7 | 整理する | ファイルに名前を付け、プロジェクトフォルダを保つ | 昨日の作業をすぐ見つけられる |
| 8 | モーションを試す | 静止画が楽に感じられるようになったら動画モデルに切り替える | 短いクリップがレンダリングされる |

初心者に最もよくある失敗は、一度に5つも変更してから、どれが改善の原因だったかを推測することです。落ち着いてください。まずライティングだけを変える。次にカメラアングルだけを変える。20回レンダリングするころには、モデルがどう反応するかの自分なりの頭の中の地図ができているはずです。

**H3: 初回レンダリングで「できた」と言える状態**

最初の出力は美しい必要はありません。必要なのは*診断的*であることです。被写体は説明したとおりか、構図は意図したものに近いか、スタイルは添付した参照画像に似ているか。この3つのうち2つが当てはまれば、順調です。

## プロンプト、参照画像、コントロール

ArtCraftでのプロンプト作成は、魔法の言葉というより構造の問題です。毎回同じスロットを埋めていけば、結果は予測可能になります。それが、スロットマシンではなくコントロール可能なツールを使う最大の理由です。

| スロット | 何を制御するか | 記述例 |
|---|---|---|
| 被写体 | フレーム内に誰／何がいるか | 「孤独な灯台守」 |
| スタイル | 画材と描画表現 | 「油彩、目に見える筆致」 |
| 構図 | フレーミングとレンズ | 「ワイドショット、三分割法」 |
| ライティング | 雰囲気と時間帯 | 「曇った夜明け、柔らかなリムライト」 |
| モーション（動画のみ） | 実際に動くもの | 「ゆっくりしたプッシュイン、砕ける波」 |
| 除外指定 | 避けたいもの | 「テキストなし、ウォーターマークなし、余分な手足なし」 |

良い結果を出す人と途中で諦める人を分ける、いくつかの習慣があります。

- **スタイルは形容詞ではなく参照画像で固定する。** 強力な参照画像1枚は、通常、3段落の説明よりも効果的です。
- **プロンプト日誌をつける。** 残したレンダリングの横に、そのプロンプトを貼っておきましょう。パターンはすぐに見えてきます。
- **うまくいった設定は再利用する。** モデルがシード値や保存済みプリセットを公開しているなら、それを保ったまま被写体だけを変えましょう。
- **バリエーションは意図的にまとめて試す。** 素早い低解像度テスト10回は、遅い高解像度の一発勝負に勝ります。
- **除外指定は短く保つ。** 長いネガティブリストは、修正する以上にモデルを混乱させることがあります。

一貫性を保つうえで、参照画像が最も重要な役割を担います。キャラクター、製品、ロケーションなどシリーズものを作る場合は、すべてのレンダリングに同じ参照セットを添付して、プロジェクト全体で見た目が安定するようにしましょう。

## 静止画からモーションへ

動画はArtCraftが本当に面白くなる領域であり、同時に新規ユーザーが最も時間を溶かす領域でもあります。頭の切り替えはこうです。画像はある瞬間を描き、動画はその瞬間に起こる*変化*を描きます。

| 設定 | 画像生成 | 動画生成 |
|---|---|---|
| 一般的なレンダリング時間 | 数秒〜数分 | 映像1秒あたりで見ても明らかに長い |
| 解像度の戦略 | 早い段階で品質を上げる | 低解像度で始めて、最後に高解像度化する |
| プロンプトの重点 | 被写体、スタイル、光 | 被写体、スタイル、光、そしてモーション |
| クリップの長さ | 該当なし | まず短いクリップ、後から延長する |
| ハードウェア負荷 | 中程度 | 高い |

ArtCraftはこれまでに動画モデルを順次追加してきました。プロジェクトはAI動画生成向けにSeedance 2.0のサポートを打ち出しています。また、オープンソースコミュニティの貢献によってモデルの選択肢は広がっていく傾向があります。特定のモデルが自分のビルドで使えると決めつける前に、サイトを確認してください。

初期ユーザーによる実践的なモーションのヒント：

- **まず静止画で絵コンテを作る。** 画像として見た目を承認してから、それをアニメーション化しましょう。動いている状態でスタイルを修正するのはコストがかかります。
- **モーションを明示的に記述する。** 「ゆっくりしたドリー前進」や「風になびく髪」といった記述が、モデルに動かす対象を与えます。
- **カメラの動きはシンプルに保つ。** 1クリップにつき1つの動き。2つあると混沌として見えます。
- **3秒のクリップから始める。** 短いループは、長いものよりもレンダリング1分あたりの学びが多くなります。

## トラブルシューティングとFAQ

### 最初の1週間によくある問題のクイック修正

| 症状 | 考えられる原因 | 対処法 |
|---|---|---|
| レンダリングに永遠にかかる | 高解像度での動画モデル | クリップを短くし、解像度を下げ、GPU負荷の高い他のアプリを閉じる |
| 出力がプロンプトを無視する | プロンプトが詰め込みすぎ | 被写体、スタイル、ライティングだけに絞る |
| アプリが起動しない | OSの不一致、またはインストールの破損 | 公式ソースから再インストールし、要件を再確認する |
| ショット間でスタイルがずれる | 参照による固定がない | 毎回同じ参照画像を添付する |
| ディスクがいっぱいになる | 管理されていないレンダリング結果とキャッシュされたモデル | 古い出力を削除し、専用の出力フォルダを設定する |
| 結果がランダムに感じる | 一度に変えすぎている変数 | 1回のレンダリングにつき設定を1つだけ変える |

### ArtCraft入門 FAQ

**ArtCraftを始めるのは、まったくの初心者には難しいですか？**
順序よく進めれば難しくありません。インストールし、静止画を1枚生成し、その1枚を反復して改善し、それからようやく動画に移ります。人が報告する難しさのほとんどは、最も重いタスクから始めてしまうことから来ています。

**高価なグラフィックスカードは必要ですか？**
画像生成なら、ミドルレンジの現行GPUでたいていは十分です。動画となるとハードウェアの重要性がはるかに増し、レンダリング時間はクリップの長さと解像度に比例します。動画ワークフローに踏み切る前に、公表されている要件と自分のマシンを照らし合わせてください。

**ArtCraftは無料で使えますか？**
コアはオープンソースで、これは自分のツールを自分で持ちたいアーティストにとって魅力の大きな部分です。個々のモデルのライセンス詳細は異なる場合があるので、商用利用の前に公式サイトで最新の条件を確認してください。

**ArtCraftで制作した作品を販売できますか？**
それはアプリだけでなく、使用したモデルによります。商用出力を許可するモデルライセンスもあれば、制限するものもあります。どのモデルがどのアセットを生成したかを記録しておけば、後で権利を確認できます。

最初のレンダリングが決まったら、本当の仕事が始まります。参照ライブラリを育て、プロンプト日誌をつけ、すべての生成を管理された実験として扱うこと。その習慣こそが——どんな個別の設定ではなく——ArtCraft入門を、ソフトウェアの学習というより、工芸の習得のように感じさせるのです。
