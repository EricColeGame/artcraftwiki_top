## ArtCraftとは何か、誰に向いているのか

ArtCraft初心者ガイドを探しているなら、手短に言えばこうです。ArtCraftはAI画像と動画を生成するためのオープンソースのデスクトップアプリケーションで、ブラックボックスではなく目に見えるコントロールを求めるアーティスト、デザイナー、映像制作者のために作られています。ブラウザタブの中ではなく通常のプログラムのようにインストールされ、開発者たちはこれを意図的に制作するためのエンジンと表現しています。プロンプトの文言から参照画像まで、あらゆる選択が自分の手元に残るツールです。

このArtCraft初心者ガイドは、アプリを一度も開いたことがない人を想定しています。機械学習の背景は不要で、拡散モデルが内部でどう動くかを知っている必要もありません。必要なのは、反復に対する忍耐です。生成し、よく見て、1つの変数を変え、また生成する。このループこそがスキルのすべてです。

何かをインストールする前に、全体像を一覧で見ておきましょう。

| 機能 | 初心者にとっての意味 |
|---|---|
| デスクトップアプリケーション | ローカルにインストールされ、タブを閉じてもセッションが消えない |
| オープンソース | コードが公開されているため、コミュニティが検査し、貢献できる |
| 画像と動画の生成 | 2つのサブスクリプションではなく、1つのツールで静止画とモーションをカバー |
| プロンプト制御 | すべての生成を動かすテキストを自分で書き、修正する |
| 参照入力 | 言葉だけでなく、例示画像で結果を誘導できる |
| ファイルは自分のドライブに書き込まれる | 出力は自分のフォルダに届き、パイプラインですぐ使える |

新規ユーザーにとっての魅力は所有感です。ArtCraftはオープンソースでデスクトップネイティブなので、作品が他人のインターフェースの中に閉じ込められません。[ArtCraftの公式GitHubリポジトリ](https://github.com/storytold/artcraft)を見れば、このプロジェクトが正確に何をし、どのように維持されているかを確認できます。

## 最初の週末を無駄にしないセットアップ

### デスクトップ第一の考え方を持つ

初心者はAIツールをウェブサイトのように扱いがちです。クリックし、生成し、閉じる。ArtCraftは逆の習慣に報います。ネイティブに動作し、結果をディスクに書き込むため、1枚生成する前に、自分の作業が*どこ*に保存されるかを決めておくべきです。単純な構造 — `ArtCraft/projects/project-name/refs`、`/outputs`、`/prompts` — が、後で何時間もスクロールする手間を省きます。

### まずこの6つを準備する

| 準備項目 | 重要な理由 | 初心者向けショートカット |
|---|---|---|
| ディスク容量 | 動画の出力は静止画よりはるかに大きい | 専用フォルダかドライブを確保する |
| 参照画像 | 言葉だけでは見た目を捉えにくい | 好きなスタイルごとに5～10枚集める |
| 命名規則 | 生成ファイルはあっという間に増える | `project-date-subject-v1` を使う |
| プロンプトメモ | うまくいった内容を忘れる | プレーンテキストのプロンプトログを付ける |
| 安定したインターネット | 一部のモデルやサービスに必要 | 長時間実行の前に接続をテストする |
| 時間ブロック | 生成は即時ではない | 30～60分のセッションで作業する |

インストールしたら、何も生成せずに10分かけてすべてのパネルをクリックして回りましょう。最初にインターフェースを探索する新規ユーザーは、1週目から一貫してより良い結果を出します。参照、プロンプト欄、出力設定が実際どこにあるかを知っているからです。

## 最初の画像：当てずっぽうなしのプロンプト

### 役に立つプロンプトの解剖

初心者のプロンプトはたいてい願い事のように読めます。「美しいファンタジーの城」。機能するプロンプトはショットリストのように読めます。感情を描写しているのではなく、写真やフレームを指定しているのです。

| プロンプト要素 | 弱い例 | 強い例 |
|---|---|---|
| 被写体 | 「騎士」 | 「傷んだ板金鎧をまとった風化した騎士」 |
| 動作・ポーズ | 「立っている」 | 「跪き、片手を折れた剣に置いている」 |
| 舞台設定 | 「屋外」 | 「夜明け、霧に覆われた荒れ地で」 |
| ライティング | 「いい光」 | 「低いサイドライト、冷たい青い影」 |
| 構図 | （なし） | 「ワイドショット、被写体はフレーム左」 |
| スタイル・媒体 | 「かっこいい」 | 「油絵、筆致が見える」 |
| ディテールレベル | （なし） | 「鎧の傷の高ディテール」 |

各要素を1行ずつ書き、それを1つの段落にまとめます。結果が違うなら、7行すべてではなく1行だけ変えます。この単一の規律が、このArtCraft初心者ガイド全体で最も価値ある習慣です。

### 参照画像でギャップを埋める

語彙が尽きたら、参照画像の出番です。ArtCraftは参照駆動のワークフローをサポートしており、モデルに視覚的な目標を渡し、構図、パレット、キャラクターデザインを尊重するよう求められます。1回の生成につき参照は1つから始めましょう。一度に5つ重ねると信号が衝突し、出力が濁ります。

## 静止画からモーションへ：動画生成の基本

動画生成は、初心者が夢中になるか、心が折れるかの分かれ目です。頭の切り替えは単純です。画像は1つの決定であり、動画は一貫性を保たなければならない決定の連続です。モーション、カメラの動き、被写体の連続性が、フレームをまたいでまとまっていなければなりません。

| 設定 | 画像での挙動 | 動画での挙動 |
|---|---|---|
| プロンプトの長さ | 短いプロンプトのほうがうまくいくことが多い | モーションとカメラの言葉がより重要 |
| 参照の使用 | スタイルと構図を左右する | キャラクターとシーンの一貫性を左右する |
| 生成時間 | 数秒から数分 | クリップごとにかなり長い |
| 反復コスト | 再生成は安価 | 高コスト — 実行前に計画する |
| 失敗の現れ方 | 見た目が違う | 見た目は正しいがモーションが壊れている |

アプリは時間とともに外部の動画モデルも統合しています。たとえばSeedance 2.0は動画生成オプションとしてArtCraftに追加されました。モデルの利用可能性は変わるため、特定のモデルを前提にプロジェクトを計画する前に、ArtCraft公式サイトやコミュニティwikiを確認してください。

最初のクリップはあえて退屈にしましょう。被写体1つ、ゆっくりしたカメラ移動1つ、3～5秒。野心的なことに挑む前に、きれいな結果を出しましょう。

## 良い一週間とイライラする一週間を分けるワークフロー習慣

初心者のフラストレーションの多くは才能の問題ではありません。プロセスの問題であり、修正可能です。

| 間違い | どのように見えるか | 修正方法 |
|---|---|---|
| 一度にすべて書き直す | 試すたびに新しいプロンプト、学びなし | 1回の実行につき1つの変数を変える |
| プロンプトログなし | 「昨日は何を入力した？」 | すべてのプロンプトを出力と一緒に保存する |
| 1回目で完璧を追う | 40回生成して、何も保存しない | 5回ごとに最良のものを保存する |
| 参照を無視する | 終わらないスタイルの漂流 | プロジェクトごとに参照を1つ固定する |
| 出力を溜め込む | 名前のないファイルが数千 | 容赦なく削除し、プロジェクトごとに10個だけ残す |

構造化された最初の一週間は、どんな単一のコツよりも役立ちます。

| 日 | 焦点 | 目標 |
|---|---|---|
| 1 | インストールしてインターフェースを見て回る | すべてがどこにあるか知る |
| 2 | プロンプトの解剖 | 意図的に構図した画像を1枚制作する |
| 3 | 参照 | 参照から特定の見た目を再現する |
| 4 | 反復の規律 | 5回の実行で1枚の画像を改善する |
| 5 | 最初の動画クリップ | きれいな3秒のモーションテスト |
| 6 | 整理 | 整ったフォルダとプロンプトログ |
| 7 | 個人プロジェクト | すべてを自分のアイデアに応用する |

コミュニティの報告は一貫して、プロンプトを記録する新規ユーザーは、勘だけで生成する人よりはるかに速く上達することを示唆しています。ユーザー体験も別の真実を指し示します。最初の20個の出力は練習であり、ポートフォリオ作品ではありません。そう捉えればプレッシャーは消えます。

## よくある質問

**始めるのに高価なコンピューターは必要ですか？**
必ずしもそうではありません。ArtCraftはデスクトップアプリなので、性能は使用するモデルと機能によります。静止画生成は一般に動画作業より軽いです。画像から始め、自分のマシンの挙動を測り、特定の機能が使えなくなったときだけアップグレードしましょう。

**AIツールを使ったことがなくても、このArtCraft初心者ガイドは役に立ちますか？**
はい。まさにそういう人のために書かれています。プロンプト構造の表を学び、参照は一度に1つ使い、すべてを一度に変えたくなる衝動を抑えましょう。この3つのルールが、ほとんどの初心者を最初の1か月支えます。

**画像と動画、先に学ぶべきはどちらですか？**
常に画像が先です。画像生成は、低コストでプロンプト、参照、反復を教えてくれます。動画は、まだ直し方を学んでいないすべてのミスを増幅するので、順序が重要です。

**何か壊れたとき、どこで助けを得られますか？**
まずArtCraft公式サイトとコミュニティwikiを見てください。ダウンロード、プロンプト制御、参照、アニメーション、オープンソースのワークフローを扱っています。より深い質問には、GitHubリポジトリのIssueとディスカッションが、他のユーザーがすでに解決した内容を確認できる最も信頼できる場所です。

**実際に気に入るものを作れるまで、どのくらいかかりますか？**
ほとんどの人は、意図的な練習の最初の1週間で残しておきたい作品を1つ作り、1か月以内に小さなポートフォリオを作ります。速さは才能よりも、プロンプトログを付けて一度に1つの変数だけを変えるかどうかにかかっています。
