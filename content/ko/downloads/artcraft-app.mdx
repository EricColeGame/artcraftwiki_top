## ArtCraft 앱이란 무엇인가?

클라우드 도구가 하룻밤 사이에 모델을 바꿔서 멋진 AI 이미지를 잃어본 적이 있다면, ArtCraft 앱이 왜 존재하는지 이미 이해하고 있을 것입니다. 이 앱은 AI 이미지와 비디오를 생성하기 위한 오픈소스 데스크톱 애플리케이션으로, 프롬프트, 레퍼런스, 출력 파일을 직접 통제하고 싶어 하는 아티스트, 디자이너, 영화 제작자를 위해 만들어졌습니다. 브라우저 탭 속 블랙박스에 접근 권한을 빌리는 대신, ArtCraft 앱을 자신의 컴퓨터에 설치하고 하나의 집중된 스튜디오 창 안에서 작업하세요.

이 차이는 들리는 것보다 더 중요합니다. 클라우드 생성기는 편리하지만, 대기열, 크레딧, 볼 수 없는 콘텐츠 필터, 소유하지 못한 파일 기록이 따라옵니다. 데스크톱 우선 도구는 이를 뒤집습니다: 렌더 결과는 내 드라이브에 저장되고, 프로젝트 파일은 내 곁에 남으며, 워크플로는 일회성 프롬프트가 아니라 반복 작업을 중심으로 설계됩니다. 프로젝트 자체 자료에서는 이를 간단히 설명합니다 — 진정한 통제를 원하는 아티스트를 위한 의도적인 제작 엔진이라고요.

- **취미 사용자** — 또 하나의 구독보다 로컬 설치를 선호하는

## 다운로드 옵션: ArtCraft 앱을 어디서 받을까

가장 먼저 이해해야 할 점은 "ArtCraft"라는 이름을 여러 무관한 사업체가 공유한다는 것입니다. 조명 제조사, 호주 간판 회사, 싱가포르 공예 스튜디오가 있습니다 — 어느 것도 AI 생성과 관련이 없습니다. 샹들리에를 판매하는 페이지에 도착했다면, 잘못된 곳에 온 것입니다. AI 프로젝트는 자체 도메인과 GitHub에 있으며, 바로 그곳에서 다운로드해야 합니다.

| 출처 | 제공 내용 | 최적 대상 |
|---|---|---|
| 공식 프로젝트 사이트 | 기본 다운로드, 릴리스 노트, 모델 발표 | 대부분의 사용자 — 여기서 시작하세요 |
| GitHub 저장소 | 소스 코드, 이슈 트래커, 빌드 지침 | 개발자 및 직접 빌드하는 사람 |
| 커뮤니티 위키 | 프롬프트 통제, 레퍼런스, 오픈소스 워크플로에 관한 튜토리얼 | 워크플로 학습 |
| 웹 앱 진입점 | 데스크톱 도구와 연결된 브라우저 기반 계정 접근 | 계정 및 프로젝트 관리 |

간단한 안전 주의사항: 이 이름이 다른 브랜드와 충돌하기 때문에, 설치 프로그램을 묶어 배포하는 제3자 "다운로드 포털"은 실제 위험입니다. 공식 경로로 바로 가세요. 어떤 사이트가 ArtCraft 앱 설치 프로그램을 주기 전에 다운로드 관리자를 설치하라고 요구한다면, 탭을 닫으세요.

### 설치 전 확인할 사항

- **운영체제 지원** — 공식 다운로드 목록에 내 OS가 있는지 확인하세요
- **GPU 성능** — 이미지, 특히 비디오 생성은 그래픽 카드에 크게 의존합니다
- **디스크 공간** — 모델 가중치는 큰 파일입니다; 넉넉한 여유 공간을 계획하세요
- **모델 라이선스** — 일부 모델은 앱과 별도의 자체 사용 약관과 함께 제공됩니다

정확한 최소 사양은 모델이 발전하면서 바뀌므로, 몇 달 전에 작성된 블로그 글보다 공식 문서를 진실의 원천으로 여기세요.

## ArtCraft 앱 설치 방법: 단계별 안내

설치는 간단하지만, 시작할 때의 몇 가지 작은 결정이 나중에 몇 시간을 절약해 줍니다. 첫 AI 도구든 열 번째 도구든 통하는 실용적인 순서입니다.

| 단계 | 작업 | 주의할 점 |
|---|---|---|
| 1 | 공식 사이트에서 설치 프로그램 다운로드 | 운영체제와 정확히 일치하는지 확인 |
| 2 | 설치 프로그램 실행 및 설치 경로 선택 | 공간이 부족하면 시스템 드라이브를 피하세요 |
| 3 | 앱 실행 후 로그인 또는 계정 생성 | 모델 접근과 업데이트에 필요 |
| 4 | 출력 폴더 설정 | 비디오 파일을 담을 공간이 있는 드라이브 선택 |
| 5 | 첫 모델 다운로드 또는 연결 | 비디오를 추가하기 전에 이미지 모델 하나로 시작 |
| 6 | 간단한 테스트 프롬프트 생성 | 파이프라인이 처음부터 끝까지 작동하는지 확인 |
| 7 | 첫 프로젝트 저장 | 파일 구조를 일찍 확립 |

일곱 번째 단계는 대부분의 사람들이 건너뛰는 단계입니다. 지금 프로젝트 이름을 어떻게 지을지 정하세요 — 클라이언트, 날짜, 콘셉트 — AI 워크플로는 파일을 빠르게 생성하고, 지저분한 드라이브는 추진력을 죽입니다.

### 처음 실행 시 바꿀 만한 설정

- **출력 디렉터리** — 데스크톱이 아니라 프로젝트 폴더를 가리키게 하세요
- **기본 해상도** — 반복 작업에는 낮게 시작하고, 최종본에는 높이세요
- **시드 처리** — 마음에 들었던 결과를 재현할 수 있도록 시드를 보이게 유지하세요
- **레퍼런스 폴더** — 스타일 레퍼런스와 캐릭터 시트를 위한 전용 공간

## 아티스트들이 실제로 사용하는 핵심 기능

마케팅 페이지는 기능을 나열하지만, 현업 아티스트는 세 네 가지만 신경 씁니다. 프로젝트가 스스로를 설명하는 방식과 커뮤니티 보고를 바탕으로, 작업 방식을 바꾸는 기능은 다음과 같습니다.

| 기능 | 워크플로에 미치는 의미 |
|---|---|
| 프롬프트 통제 | 단일 텍스트 상자에 기대는 대신 세밀한 방향 제시 |
| 레퍼런스 이미지 | 결과가 의도한 모델에 맞게 유지되도록 스타일과 피사체 가이드 제공 |
| 애니메이션 / 비디오 생성 | 스틸과 프롬프트를 움직이는 클립으로 전환 |
| 한 창에서의 모델 접근 | 새 도구 없이 이미지와 비디오 모델 전환 |
| 로컬 파일 출력 | 결과가 바로 내 드라이브에 기록됨 |
| 오픈소스 워크플로 | 파이프라인을 직접 검사, 확장, 조정 가능 |

비디오 쪽은 ArtCraft 앱이 가장 분명하게 차별화되는 부분입니다. 이미지 생성은 상품화되었지만, 일관된 모션을 얻는 것은 여전히 어렵습니다. 이 프로젝트는 Seedance 2.0을 포함한 비디오 모델 지원을 추가했으므로, 별도 파이프라인으로 내보내지 않고도 스틸 콘셉트에서 짧은 클립으로 이동할 수 있습니다.

### 현실적인 시작 워크플로

1. 주제, 조명, 렌즈, 분위기를 설명하는 프롬프트를 — 이 순서대로 — 작성합니다.
2. 마음에 드는 방향을 찾기 위해 저해상도 배치를 생성합니다.
3. 가장 좋아하는 결과의 시드를 고정합니다.
4. 스타일이나 캐릭터 일관성을 강화하기 위해 레퍼런스 이미지를 추가합니다.
5. 최종 해상도로 업스케일하거나 다시 렌더링합니다.
6. 스틸을 비디오 모델에 넘겨 짧은 애니메이션 패스를 만듭니다.
7. 전체 체인이 재현 가능하도록 프로젝트를 저장합니다.

커뮤니티 보고는 두 번째 단계 — 비싼 최종본 전에 저렴하게 반복하기 — 가 매끄러운 세션과 답답한 세션을 가르는 요소라고 일관되게 말합니다.

- **피사체만이 아니라 빛을 구체적으로 설명하세요.** "골든 아워, 역광, 얕은 심도"가 "아름다운"보다 더 좋은 결과를 냅니다.
- **일관성을 위해 레퍼런스를 사용하세요.** 텍스트만으로는 반복 등장 캐릭터를 다루기 어렵지만, 이미지는 그렇지 않습니다.
- **저해상도로 반복하세요.** 탐색 중에는 속도가 완성도보다 중요합니다.
- **프롬프트 로그를 유지하세요.** 어떤 것이 효과가 있었을 때, 다음 달에 다시 재현하고 싶을 것입니다.
- **비디오 시도를 일괄로 진행하세요.** 모션은 변동성이 크므로, 클립 하나로 모델을 판단하기에 충분하지 않습니다.
- **출력 폴더를 백업하세요.** 로컬 소유권은 실제로 백업할 때만 도움이 됩니다.
- **저장소를 읽어보세요.** GitHub 프로젝트는 릴리스에서 무엇이 바뀌었고 다음에 무엇이 계획되어 있는지 이해하는 가장 빠른 방법입니다.

## 자주 묻는 질문

**ArtCraft 앱은 무료로 다운로드할 수 있나요?**
애플리케이션 자체는 오픈소스이므로 소프트웨어 사용에 라이선스 비용이 없습니다. 로드하는 개별 AI 모델에는 자체 약관이 있을 수 있으며, 클라우드 기반 모델 접근에는 해당 제공업체가 정한 비용이 발생할 수 있습니다. 예산을 계획하기 전에 공식 사이트에서 현재 세부 정보를 확인하세요.

**ArtCraft 앱을 오프라인으로 실행할 수 있나요?**
부분적으로 가능합니다. 로컬 모델을 설치하면 연결 없이 자체 하드웨어에서 생성할 수 있습니다. 원격 서버에서 실행되는 모델은 당연히 인터넷 접속이 필요합니다. 앱은 어느 경우든 파일을 로컬에 유지하도록 설계되었습니다.

**어떤 하드웨어가 필요한가요?**
합리적으로 성능이 괜찮은 GPU가 있는 데스크톱 머신이 실용적인 출발점이며, 특히 비디오에 그렇습니다. 요구 사항은 새 모델이 출시되면서 바뀌므로, 오래된 가이드에 의존하기보다 공식 다운로드 페이지에서 현재 권장 사항을 확인하세요.

**이것이 조명이나 간판 회사의 ArtCraft와 같은 건가요?**
아닙니다. 그것들은 전혀 별개의 사업체이며 관련 없는 산업입니다. 여기서 다루는 ArtCraft 앱은 오픈소스 AI 이미지 및 비디오 도구이며, 자체 공식 채널과 공개 저장소를 통해서만 배포됩니다.
