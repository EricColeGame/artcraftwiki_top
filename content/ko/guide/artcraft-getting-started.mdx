ArtCraft는 AI 이미지와 비디오를 생성하기 위한 오픈소스 데스크톱 앱입니다. 설정을 프리셋 뒤에 숨겨 놓는 브라우저 도구들에 답답함을 느껴본 적이 있다면, 이 앱은 충분히 시간을 들일 가치가 있습니다. 이 ArtCraft 시작하기 가이드는 사전 AI 경험이 전혀 없다고 가정하고 설치, 첫 프롬프트, 레퍼런스 이미지, 그리고 애니메이션까지 안내합니다. ArtCraft 시작하기의 핵심은 단순합니다. 모델이 당신을 이끄는 것이 아니라, 당신이 모델을 이끄는 것입니다.

아래에는 체크리스트, 단계별 표, 프롬프트 프레임워크, 그리고 거의 모든 신규 사용자가 첫 주에 겪는 문제들에 대한 해결책이 담겨 있습니다.

## ArtCraft란 무엇이며 누구를 위한 것인가

ArtCraft는 AI 이미지 및 비디오 생성을 위한 네이티브 데스크톱 애플리케이션으로, 의도적인 제어를 원하는 아티스트, 디자이너, 영화 제작자를 위해 만들어졌습니다. 이 프로젝트는 스스로를 "의도적 제작 엔진(intentional crafting engine)"이라고 설명하는데, 이는 그 철학을 잘 담아냅니다. 당신이 선택하고, 결과를 검토하고, 파일을 자신의 컴퓨터에 보관하는 것입니다.

브라우저 탭이 아니라 설치형 앱으로 실행되기 때문에 레퍼런스, 프로젝트, 렌더 결과물이 모두 자신의 폴더에 저장됩니다. 계정 접근을 위한 웹 동반 서비스도 있지만, 실제 생성 작업은 데스크톱 클라이언트에서 이루어집니다. 프로젝트 자체의 설명은 [ArtCraft 공식 사이트](https://getartcraft.com/)에서 읽어볼 수 있고, [GitHub의 오픈소스 저장소](https://github.com/storytold/artcraft)에서는 이 엔진이 내부적으로 정확히 무엇을 하는지 확인할 수 있습니다.

| 항목 | ArtCraft (데스크톱, 오픈소스) | 일반적인 브라우저 생성기 |
|---|---|---|
| 실행 환경 | 설치형 데스크톱 앱 | 브라우저 탭 |
| 소스 코드 | 공개 및 커뮤니티 검증 가능 | 비공개 |
| 프롬프트 제어 | 상세한 모델 수준 설정 | 단순화된 프리셋 |
| 모델 지원 | 비디오 모델을 포함해 시간이 지나며 여러 모델 추가 | 보통 하나의 고정 모델 |
| 파일 처리 | 렌더 결과물을 자신의 저장소에 저장 | 클라우드 라이브러리 |
| 설정 | 한 번의 설치와 모델 다운로드 | 즉시 가입 |

누구를 위한 것일까요? 컨셉 아티스트, 일러스트레이터, 모션 디자이너, 인디 영화 제작자, 그리고 실험을 즐기는 취미 사용자입니다. 누구를 위한 것이 아닐까요? 버튼 하나로 완성된 영화가 나오기를 바라는 사람입니다. ArtCraft는 반복 작업에 보상을 주며, 그것은 결함이 아니라 장점입니다.

## ArtCraft 시작하기: 사전 점검 체크리스트

여기서 5분만 투자하면 한 시간의 좌절을 아낄 수 있습니다. 첫날 발생하는 대부분의 문제는 소프트웨어 자체가 아니라 준비되지 않은 컴퓨터에서 비롯됩니다.

| 점검 항목 | 중요한 이유 | 확인 방법 |
|---|---|---|
| 지원 운영체제 | 데스크톱 빌드가 자신의 플랫폼과 맞아야 함 | 공식 사이트의 다운로드 페이지 확인 |
| GPU와 비디오 메모리 | 이미지 작업은 적당하지만 비디오 작업은 그래픽 카드에 크게 의존 | 공개된 요구사항과 자신의 GPU 비교 |
| 여유 디스크 공간 | 모델과 렌더 결과물은 큰 파일임 | 설치 전에 넉넉한 여유 공간 확보 |
| 안정적인 인터넷 | 모델은 처음 사용할 때 다운로드됨 | 유선 연결 또는 강한 Wi-Fi |
| 레퍼런스 폴더 | 레퍼런스는 말보다 훨씬 잘 스타일과 구도를 이끌어줌 | 마음에 드는 이미지 5~10장 모으기 |
| 계정 | 웹 동반 서비스와 일부 클라우드 기능에 필요 | 공식 앱 포털을 통해 등록 |

커뮤니티 보고에서 나온 두 가지 참고사항: 제3자 미러는 구버전 빌드를 배포할 수 있으니 공식 출처에서만 설치하고, 비디오를 시도하기 전에 이미지 생성부터 시작하세요. 비디오 렌더링은 훨씬 무겁고, 첫 세션을 느린 렌더링을 기다리며 보내는 것은 나쁜 첫인상입니다.

## 첫 세션, 단계별로

이것이 ArtCraft 시작하기의 핵심이니, 레시피처럼 다루세요. 한 번 따라 하면 인터페이스가 더 이상 낯설지 않게 됩니다.

| # | 단계 | 하는 일 | 성공의 모습 |
|---|---|---|---|
| 1 | 다운로드 | 공식 사이트에서 데스크톱 빌드 받기 | 설치 프로그램이 문제없이 실행됨 |
| 2 | 설치 | 설치 프로그램을 실행하고 필요한 것을 가져오게 함 | 앱이 워크스페이스와 함께 열림 |
| 3 | 로그인 | 요청되면 로그인 | 워크스페이스가 정상적으로 로드됨 |
| 4 | 이미지 모델 선택 | 비디오로 시작하고 싶은 유혹을 참기 | 모델이 선택되어 준비됨 |
| 5 | 첫 프롬프트 작성 | 하나의 주제, 하나의 스타일, 하나의 조명 메모 | 출력 패널에 미리보기 등장 |
| 6 | 반복 | 렌더마다 변수 하나만 변경 | 각 시도가 구체적인 무언가를 가르쳐줌 |
| 7 | 정리 | 파일에 이름을 붙이고 프로젝트 폴더 유지 | 어제 작업을 찾을 수 있음 |
| 8 | 모션 시도 | 스틸이 쉬워지면 비디오 모델로 전환 | 짧은 클립이 렌더됨 |

초보자가 가장 흔히 하는 실수는 한 번에 다섯 가지를 바꾸고 나서 어떤 것이 개선을 일으켰는지 추측하는 것입니다. 속도를 늦추세요. 조명만 바꿔보세요. 그다음 카메라 앵글만 바꿔보세요. 스무 번의 렌더 안에 모델이 어떻게 반응하는지에 대한 개인적인 지도가 머릿속에 그려질 것입니다.

**H3: 첫 렌더에서 "완료"란 어떤 모습인가**

첫 결과물이 아름다울 필요는 없습니다. *진단적*이어야 합니다. 주제가 묘사한 것과 일치하는가, 구도가 의도한 것에 가까운가, 스타일이 첨부한 레퍼런스와 닮았는가? 이 세 가지 중 두 가지가 맞다면 제대로 가고 있는 것입니다.

## 프롬프트 작성, 레퍼런스, 제어

ArtCraft에서 프롬프트 작성은 마법의 단어보다 구조에 가깝습니다. 매번 같은 슬롯을 채우면 결과가 예측 가능해집니다. 이것이 슬롯 머신 대신 제어 가능한 도구를 사용하는 이유 전체입니다.

| 슬롯 | 제어하는 것 | 예시 표현 |
|---|---|---|
| 주제 | 프레임 안에 누가 또는 무엇이 있는가 | "외로운 등대지기" |
| 스타일 | 매체와 렌더링 | "유화, 눈에 보이는 붓터치" |
| 구도 | 프레이밍과 렌즈 | "와이드 샷, 삼분할 법칙" |
| 조명 | 분위기와 시간대 | "흐린 새벽, 부드러운 림 라이트" |
| 모션 (비디오 전용) | 실제로 움직이는 것 | "느린 푸시인, 부서지는 파도" |
| 제외 항목 | 피해야 할 것 | "텍스트 없음, 워터마크 없음, 추가 팔다리 없음" |

좋은 결과를 얻는 사람과 포기하는 사람을 가르는 몇 가지 습관:

- **형용사가 아니라 레퍼런스로 스타일을 고정하세요.** 강력한 레퍼런스 이미지 한 장이 보통 세 문단의 설명보다 낫습니다.
- **프롬프트 일지를 쓰세요.** 남긴 렌더 옆에 각 프롬프트를 붙여 넣으세요. 패턴이 빠르게 드러납니다.
- **효과가 있었던 설정을 재사용하세요.** 모델이 시드나 저장된 프리셋을 제공한다면 그것을 유지하고 주제만 바꾸세요.
- **의도적으로 변형을 배치 처리하세요.** 빠른 저해상도 테스트 열 번이 느린 고해상도 도박 한 번보다 낫습니다.
- **제외 항목은 짧게 유지하세요.** 긴 네거티브 목록은 바로잡기보다 혼란을 더 키울 수 있습니다.

레퍼런스 이미지가 일관성을 위한 무거운 작업을 담당합니다. 시리즈를 만들고 있다면 — 캐릭터, 제품, 장소 등 — 모든 렌더에 동일한 레퍼런스 세트를 첨부해서 전체 프로젝트에 걸쳐 룩이 안정적으로 유지되게 하세요.

## 스틸에서 모션으로

비디오는 ArtCraft가 진정으로 흥미로워지는 지점이며, 동시에 신규 사용자가 가장 많은 시간을 소모하는 지점이기도 합니다. 사고의 전환은 이렇습니다. 이미지는 한 순간을 묘사하지만, 비디오는 그 순간에 걸친 *변화*를 묘사합니다.

| 설정 | 이미지 생성 | 비디오 생성 |
|---|---|---|
| 일반적인 렌더 시간 | 몇 초에서 1~2분 | 영상 1초당 눈에 띄게 더 길다 |
| 해상도 전략 | 초반에 품질을 밀어붙임 | 낮게 시작해 높게 마무리 |
| 프롬프트 초점 | 주제, 스타일, 조명 | 주제, 스타일, 조명, 그리고 모션 |
| 클립 길이 | 해당 없음 | 짧은 클립 먼저, 나중에 연장 |
| 하드웨어 부담 | 보통 | 높음 |

ArtCraft는 시간이 지나며 비디오 모델을 추가해 왔습니다. 이 프로젝트는 AI 비디오 생성을 위한 Seedance 2.0 지원을 홍보한 바 있으며, 모델 옵션은 오픈소스 커뮤니티가 기여함에 따라 확장되는 경향이 있습니다. 자신의 빌드에서 특정 모델이 사용 가능하다고 가정하기 전에 사이트를 확인하세요.

초기 사용자들이 전하는 실용적인 모션 팁:

- **스틸로 먼저 스토리보드하세요.** 룩을 이미지로 승인한 다음 애니메이션화하세요. 모션 상태에서 스타일을 고치는 것은 비쌉니다.
- **모션을 명시적으로 묘사하세요.** "느린 달리 전진" 또는 "바람에 흔들리는 머리카락"은 모델에게 애니메이션할 무언가를 줍니다.
- **카메라 무브는 단순하게 유지하세요.** 클립당 한 번의 무브. 두 번의 무브는 혼란으로 읽힙니다.
- **3초 클립으로 시작하세요.** 짧은 루프는 긴 것보다 렌더링 시간 대비 더 많은 것을 가르쳐줍니다.

## 문제 해결과 FAQ

### 첫 주에 흔히 겪는 문제에 대한 빠른 해결책

| 증상 | 가능한 원인 | 해결 |
|---|---|---|
| 렌더가 끝없이 걸림 | 높은 해상도의 비디오 모델 | 클립을 줄이고, 해상도를 낮추고, 다른 GPU 집약적 앱 종료 |
| 출력이 프롬프트를 무시함 | 프롬프트가 과부하됨 | 주제, 스타일, 조명으로 줄이기 |
| 앱이 실행되지 않음 | OS 불일치 또는 손상된 설치 | 공식 출처에서 재설치하고 요구사항 재확인 |
| 샷마다 스타일이 달라짐 | 레퍼런스 고정 없음 | 매번 동일한 레퍼런스 이미지 첨부 |
| 디스크가 가득 참 | 관리되지 않는 렌더와 캐시된 모델 | 오래된 출력물 정리하고 전용 출력 폴더 설정 |
| 결과가 무작위로 느껴짐 | 한 번에 너무 많은 변수 변경 | 렌더당 설정 하나만 변경 |

### ArtCraft 시작하기 FAQ

**ArtCraft 시작하기는 완전한 초보자에게 어려운가요?**
순서를 제대로 지키면 그렇지 않습니다. 설치하고, 스틸 이미지 하나를 생성하고, 그 한 이미지에 대해 반복하고, 그다음에야 비디오로 넘어가세요. 사람들이 보고하는 어려움의 대부분은 가장 무거운 작업부터 시작하기 때문에 생깁니다.

**비싼 그래픽 카드가 필요한가요?**
이미지 생성의 경우 중급대의 최신 GPU면 보통 충분합니다. 비디오의 경우 하드웨어가 훨씬 더 중요하며, 렌더 시간은 클립 길이와 해상도에 따라 늘어납니다. 비디오 워크플로에 전념하기 전에 공개된 요구사항을 자신의 컴퓨터와 비교해 확인하세요.

**ArtCraft는 무료로 사용할 수 있나요?**
핵심은 오픈소스이며, 이는 자신의 도구를 소유하고자 하는 아티스트에게 큰 매력입니다. 개별 모델의 라이선스 세부사항은 다를 수 있으니 상업적 사용 전에 공식 사이트에서 현재 약관을 확인하세요.

**ArtCraft에서 만든 작업물을 판매할 수 있나요?**
