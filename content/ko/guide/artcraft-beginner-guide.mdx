## ArtCraft란 무엇이며 누구를 위한 도구인가

ArtCraft 초보자 가이드를 찾고 있었다면, 짧게 말해 이렇습니다. ArtCraft는 AI 이미지와 비디오를 생성하기 위한 오픈 소스 데스크톱 애플리케이션으로, 블랙박스 대신 눈에 보이는 통제를 원하는 아티스트, 디자이너, 영화 제작자를 위해 만들어졌습니다. 브라우저 탭에 머무는 대신 일반 프로그램처럼 설치되며, 개발자들은 이를 의도적인 크래프팅 엔진 — 프롬프트 문구부터 레퍼런스 이미지까지 모든 선택이 여러분의 손에 남는 도구 — 라고 설명합니다.

이 ArtCraft 초보자 가이드는 여러분이 앱을 한 번도 열어본 적 없다고 가정합니다. 머신러닝 배경이 필요하지 않고, 디퓨전 모델이 내부적으로 어떻게 작동하는지 알 필요도 없습니다. 필요한 것은 반복에 대한 인내심입니다. 생성하고, 자세히 보고, 변수 하나를 바꾸고, 다시 생성하세요. 그 루프가 바로 전부입니다.

무엇이든 설치하기 전에 한눈에 보는 전체 그림은 다음과 같습니다.

| 기능 | 초보자에게 의미하는 것 |
|---|---|
| 데스크톱 애플리케이션 | 로컬에 설치되며, 탭을 닫아도 세션이 사라지지 않음 |
| 오픈 소스 | 코드가 공개되어 커뮤니티가 검토하고 기여할 수 있음 |
| 이미지 및 비디오 생성 | 두 개의 구독 대신 하나의 도구로 스틸과 모션을 모두 커버 |
| 프롬프트 제어 | 모든 생성을 이끄는 텍스트를 직접 작성하고 수정 |
| 레퍼런스 입력 | 말뿐 아니라 예시 이미지로 결과를 조정할 수 있음 |
| 드라이브에 저장되는 파일 | 결과물이 자신의 폴더에 저장되어 파이프라인에 바로 사용 가능 |

새 사용자에게 매력적인 점은 소유권입니다. ArtCraft는 오픈 소스이자 데스크톱 네이티브이므로, 여러분의 작업이 다른 사람의 인터페이스 안에 갇히지 않습니다. [GitHub의 공식 ArtCraft 저장소](https://github.com/storytold/artcraft)를 둘러보면 프로젝트가 정확히 무엇을 하는지, 어떻게 유지 관리되는지 확인할 수 있습니다.

## 첫 주말을 낭비하지 않고 설정하기

### 데스크톱 우선 사고방식 받아들이기

초보자는 종종 AI 도구를 웹사이트처럼 다룹니다. 클릭하고, 생성하고, 닫습니다. ArtCraft는 반대 습관에 보상을 줍니다. 네이티브로 실행되고 결과를 디스크에 저장하므로, 이미지를 단 하나 생성하기 전에 작업물이 *어디에* 저장될지 결정해야 합니다. 간단한 구조 — `ArtCraft/projects/project-name/refs`, `/outputs`, `/prompts` — 를 만들어두면 나중에 스크롤하느라 몇 시간을 아낄 수 있습니다.

### 먼저 이 여섯 가지를 준비하세요

| 준비 항목 | 중요한 이유 | 초보자용 요령 |
|---|---|---|
| 디스크 공간 | 비디오 출력은 스틸보다 훨씬 큼 | 전용 폴더나 드라이브 확보 |
| 레퍼런스 이미지 | 말만으로는 룩을 거의 담아내기 어려움 | 좋아하는 스타일마다 5–10장 수집 |
| 명명 규칙 | 생성 파일이 빠르게 늘어남 | `project-date-subject-v1` 사용 |
| 프롬프트 메모 | 무엇이 효과 있었는지 잊게 됨 | 일반 텍스트 프롬프트 로그 유지 |
| 안정적인 인터넷 | 일부 모델이나 서비스에 필요 | 긴 작업 전에 연결 테스트 |
| 시간 블록 | 생성은 즉시 끝나지 않음 | 30–60분 세션으로 작업 |

설치한 후에는 아무것도 생성하지 않고 10분 동안 모든 패널을 클릭해 보세요. 인터페이스를 먼저 탐색한 신규 사용자는 첫 주에 일관되게 더 나은 결과를 냅니다. 레퍼런스, 프롬프트 필드, 출력 설정이 실제로 어디에 있는지 알기 때문입니다.

## 첫 이미지: 추측 없이 프롬프트 작성하기

### 유용한 프롬프트의 해부

초보자 프롬프트는 보통 소원처럼 읽힙니다. "아름다운 판타지 성." 작동하는 프롬프트는 촬영 목록처럼 읽힙니다. 감정을 묘사하는 것이 아니라 사진이나 프레임을 지정하는 것입니다.

| 프롬프트 요소 | 약한 예시 | 강한 예시 |
|---|---|---|
| 주제 | "기사" | "움푹 들어간 판금 갑옷을 입은 풍파를 겪은 기사" |
| 행동 또는 자세 | "서 있음" | "무릎을 꿇고, 한 손은 부러진 검 위에" |
| 배경 | "야외" | "새벽, 안개 덮인 황무지에서" |
| 조명 | "좋은 빛" | "낮은 측광, 차가운 푸른 그림자" |
| 구도 | (없음) | "와이드 샷, 피사체는 프레임 왼쪽" |
| 스타일 또는 매체 | "멋짐" | "유화, 붓터치가 보임" |
| 디테일 수준 | (없음) | "갑옷 긁힘에 높은 디테일" |

각 요소마다 한 줄씩 쓰고, 그런 다음 하나의 문단으로 합치세요. 결과가 잘못되면 일곱 줄 전부가 아니라 한 줄만 바꾸세요. 이 단 하나의 규율이 이 ArtCraft 초보자 가이드 전체에서 가장 가치 있는 습관입니다.

### 격차를 좁히기 위해 레퍼런스 사용하기

어휘가 바닥나면 레퍼런스가 그 역할을 대신합니다. ArtCraft는 레퍼런스 기반 워크플로를 지원하므로, 모델에 시각적 목표를 제시하고 구도, 색감, 캐릭터 디자인을 존중하도록 요청할 수 있습니다. 생성마다 레퍼런스 하나로 시작하세요. 다섯 개의 레퍼런스를 한꺼번에 쌓으면 상충하는 신호가 생겨 결과물이 흐려집니다.

## 스틸에서 모션으로: 비디오 생성 기초

비디오 생성은 초보자가 사랑에 빠지거나 좌절하는 지점입니다. 사고 전환은 간단합니다. 이미지는 하나의 결정이고, 비디오는 일관성을 유지해야 하는 일련의 결정입니다. 모션, 카메라 움직임, 피사체 연속성이 모든 프레임에 걸쳐 함께 유지되어야 합니다.

| 설정 | 이미지에서의 작동 방식 | 비디오에서의 작동 방식 |
|---|---|---|
| 프롬프트 길이 | 짧은 프롬프트가 종종 더 잘 작동 | 모션과 카메라 단어가 더 중요 |
| 레퍼런스 사용 | 스타일과 구도를 이끎 | 캐릭터와 장면 일관성을 이끎 |
| 생성 시간 | 몇 초에서 몇 분 | 클립당 상당히 더 김 |
| 반복 비용 | 다시 돌리기 저렴 | 비쌈 — 실행 전에 계획 |
| 실패 방식 | 잘못된 룩 | 룩은 맞지만 모션이 깨짐 |

이 앱은 시간이 지나면서 외부 비디오 모델도 통합합니다. 예를 들어 Seedance 2.0은 ArtCraft에 비디오 생성 옵션으로 추가되었습니다. 모델 가용성은 변하므로, 특정 모델 하나를 중심으로 프로젝트를 계획하기 전에 공식 ArtCraft 사이트나 커뮤니티 위키를 확인하세요.

첫 클립은 일부러 지루하게 만드세요. 피사체 하나, 느린 카메라 무브 하나, 3~5초. 야심찬 시도를 하기 전에 깔끔한 결과를 먼저 얻으세요.

## 좋은 한 주와 답답한 한 주를 가르는 워크플로 습관

대부분의 초보자 좌절은 재능 문제가 아닙니다. 과정 문제이며, 고칠 수 있습니다.

| 실수 | 나타나는 모습 | 해결책 |
|---|---|---|
| 한 번에 전부 다시 쓰기 | 시도마다 새 프롬프트, 배움 없음 | 실행마다 변수 하나 변경 |
| 프롬프트 로그 없음 | "어제 뭐라고 입력했지?" | 모든 프롬프트를 결과물과 함께 저장 |
| 첫 시도에 완벽 추구 | 40번 생성, 저장한 것 없음 | 다섯 번마다 최고를 저장 |
| 레퍼런스 무시 | 끝없는 스타일 표류 | 프로젝트마다 레퍼런스 하나 고정 |
| 결과물 사재기 | 이름 없는 파일 수천 개 | 과감히 삭제, 프로젝트마다 열 개 유지 |

체계적인 첫 주는 어떤 단일 팁보다 더 도움이 됩니다.

| 일차 | 초점 | 목표 |
|---|---|---|
| 1 | 설치 및 인터페이스 둘러보기 | 모든 것이 어디에 있는지 파악 |
| 2 | 프롬프트 해부 | 의도적으로 구도 잡은 이미지 하나 제작 |
| 3 | 레퍼런스 | 레퍼런스에서 특정 룩 재현 |
| 4 | 반복 규율 | 다섯 번 실행으로 이미지 하나 개선 |
| 5 | 첫 비디오 클립 | 깔끔한 3초 모션 테스트 |
| 6 | 정리 | 깔끔한 폴더와 프롬프트 로그 |
| 7 | 개인 프로젝트 | 모든 것을 자신의 아이디어에 적용 |

커뮤니티 보고에 따르면 프롬프트를 기록하는 신규 사용자는 본능만으로 생성하는 사람보다 훨씬 빠르게 향상됩니다. 플레이어 경험은 또 다른 진실을 가리킵니다. 처음 스무 개의 결과물은 포트폴리오 작품이 아니라 연습입니다. 그렇게 대하면 압박감이 사라집니다.

## 자주 묻는 질문

**시작하려면 비싼 컴퓨터가 필요한가요?**
반드시 그렇지는 않습니다. ArtCraft는 데스크톱 앱이므로 성능은 사용하는 모델과 기능에 따라 달라집니다. 스틸 이미지 생성은 일반적으로 비디오 작업보다 가볍습니다. 이미지부터 시작하고, 자신의 컴퓨터 동작을 측정하고, 특정 기능을 쓸 수 없게 될 때만 업그레이드하세요.

**AI 도구를 한 번도 써본 적 없어도 이 ArtCraft 초보자 가이드가 유용한가요?**
네 — 바로 그런 분을 위해 쓰였습니다. 프롬프트 구조 표를 익히고, 한 번에 레퍼런스 하나를 사용하고, 모든 것을 한꺼번에 바꾸고 싶은 충동을 참으세요. 이 세 가지 규칙이 대부분의 초보자를 첫 달 동안 이끌어 줍니다.

**이미지와 비디오 중 무엇을 먼저 배워야 하나요?**
항상 이미지가 먼저입니다. 이미지 생성은 낮은 비용으로 프롬프트, 레퍼런스, 반복을 가르쳐 줍니다. 비디오는 아직 고치는 법을 배우지 못한 모든 실수를 증폭시키므로 순서가 중요합니다.

**문제가 생기면 어디서 도움을 받나요?**
공식 ArtCraft 사이트와 커뮤니티 위키부터 시작하세요. 다운로드, 프롬프트 제어, 레퍼런스, 애니메이션, 오픈 소스 워크플로를 다룹니다. 더 깊은 질문은 GitHub 저장소의 이슈와 토론이 다른 사용자가 이미 해결한 내용을 확인할 수 있는 가장 신뢰할 만한 곳입니다.

**실제로 마음에 드는 결과물을 만들기까지 얼마나 걸리나요?**
대부분의 사람은 의도적인 연습 첫 주 안에 남길 만한 결과물을 만들고, 한 달 안에 작은 포트폴리오를 만듭니다. 속도는 재능보다 프롬프트 로그를 유지하고 한 번에 변수 하나를 바꾸는지에 달려 있습니다.
