### Troubleshooting Your ArtCraft Download

| Symptom | Likely cause | Fix |
|---|---|---|
| Installer blocked or quarantined | OS security flagging an unfamiliar file | Allow it through security settings, then re-run |
| App opens, then closes | GPU driver mismatch or missing runtime | Update drivers, restart, relaunch |
| Renders crawl | Model too heavy for your hardware | Drop resolution, shorten clips, reduce steps |
| Model download stalls | Network interruption | Pause and resume, or switch to a wired connection |
| Output ignores your prompt | Prompt too vague, no references supplied | Add reference images and get specific |
| Can't find finished renders | Default output location | Assign a project folder and check it |

Community reports consistently point to the same pattern: driver updates and output-folder discipline solve the majority of first-day problems.

## Tips for Better Results After the ArtCraft Download

Getting the app installed is the easy part. Getting output you would actually put in a portfolio takes method.

- **Layer your prompts.** Describe subject, then style, then lighting, then camera. Vague prompts produce vague frames.
- **Lead with references.** One strong reference image often does more than three paragraphs of description.
- **Iterate small, finish big.** Lock composition at low resolution, then push quality only on the frames that earn it.
- **Keep a prompt journal.** Record what worked, including settings. Reproducibility is the whole point of a local workflow.
- **Organize by project.** One folder per project, with a subfolder for references and another for exports.
- **Update deliberately.** Open-source projects move fast; read release notes before updating mid-project.
- **Test one variable at a time.** Change the model, the prompt, or the reference — not all three at once.

| Habit | Short-term cost | Long-term payoff |
|---|---|---|
| Prompt journaling | A few minutes per session | A reusable library of proven prompts |
| Reference folders | Setup time upfront | Consistent characters and brand look |
| Low-res iteration | Slightly slower start | Fewer wasted high-quality renders |
| Project-based file structure | Discipline | You can find anything months later |

For anyone coming from cloud tools, the biggest adjustment is that responsibility shifts to you. There is no support queue for a bad prompt — but there is also no credit meter running while you experiment. Once your ArtCraft download is running, the marginal cost of trying one more idea drops to nearly nothing, and that changes how freely you explore.

**What can I actually create with ArtCraft?**
The app covers both AI image generation and AI video generation. Most artists start with stills to dial in a look, then move to short animated clips once prompts and references are producing consistent results.

**Do I need a powerful computer to run it?**
It helps considerably, especially for video. Image generation is more forgiving, so a reasonable starting strategy is to install, test images first, and keep clips short until you understand how your hardware handles the workload. Up-to-date GPU drivers matter as much as raw specs.
