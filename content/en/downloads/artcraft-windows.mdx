## First-Run Setup: Getting a Result You Actually Like

The first generation is rarely the one you keep. What separates a frustrating session from a productive one is how you set up the app before you start prompting.

| Setting | Sensible starting point | Effect |
|---|---|---|
| Output folder | A dedicated drive with free space | Keeps projects organized and easy to back up |
| Reference images | One or two strong references, not ten | Clearer guidance, less visual noise |
| Prompt length | Specific but not novel-length | Easier to isolate what changed between takes |

| Model choice | Match the model to the task | Image models for stills, video models for motion |

### Three Habits That Save Hours

- **Change one variable at a time.** If you rewrite the prompt, swap the reference, and change the model simultaneously, you learn nothing from the result.
- **Name your exports meaningfully.** `shot03_v2_seedance` beats `output_final_final` every single time.
- **Keep a prompt log.** A plain text file with the prompt, settings, and a one-line verdict turns guesswork into a repeatable process.

Artists who generate video in desktop apps often report that the biggest quality jump comes not from a new model but from tightening their own workflow. That tracks with ArtCraft's design philosophy: the app gives you levers, and the levers only help if you pull them deliberately.

## Troubleshooting Common Windows Issues

Most problems people hit after an **artcraft windows** install fall into a handful of predictable categories. Here is how to work through them.

| Symptom | Likely cause | Fix |
|---|---|---|
| Installer will not run | Windows SmartScreen blocking an unknown publisher | Verify the download source, then allow it through |
| App launches but generations fail | Insufficient GPU memory or outdated graphics drivers | Update drivers and try a smaller resolution |
| Very slow generation | Model too heavy for the hardware | Switch to a lighter model or reduce output size |
| Output files "missing" | Default save location is unfamiliar | Set the output folder explicitly in settings |
| App freezes mid-render | Resource contention with other heavy apps | Close background editors and browsers during renders |
| Unexpected behavior after an update | Cached settings from an older build | Clear app cache or reinstall the current version |

For anything beyond these basics, the GitHub issue tracker is the right place to look. Community reports often surface fixes long before they reach a documentation page, and searching existing issues can save you from filing a duplicate.

### A Quick Word on Hardware Realism

Video generation is heavier than image generation, full stop. A machine that handles stills comfortably may struggle with motion at high resolution. Start with images, confirm everything works, and then move to video at modest settings before pushing higher. That progression prevents the most common early frustration: assuming the app is broken when it is simply being asked to do too much at once.
