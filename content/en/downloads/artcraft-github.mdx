## Tips for Getting More Out of the ArtCraft GitHub Project

A little preparation turns a rocky first install into a smooth working setup.

- **Read the wiki before the code.** The ArtCraft Wiki covers prompts, references, animation, and open-source workflows in plain language. Start there, not in the source tree.
- **Bookmark the releases page.** That is where you learn about new builds, model additions, and fixes. Checking it monthly keeps you current without living in the repository.
- **Keep a reference library.** Since ArtCraft leans on reference-driven prompting, a well-organized folder of style anchors and composition examples pays for itself immediately.
- **Start small and scale up.** Generate short, low-cost test renders while you learn the controls. Save the ambitious multi-shot sequences for after you trust your settings.
- **Write reproducible bug reports.** Note your operating system, your build, and the exact steps that triggered the problem. Maintainers triage faster when they can reproduce what you saw.
- **Contribute in whatever form fits.** Documentation fixes, example prompts, and interface suggestions are all legitimate contributions, not just code patches.

| Common first-run pitfall | Practical fix |
|---|---|
| Skipping the documentation and guessing at controls | Spend fifteen minutes in the wiki first |
| Building from source on a stale toolchain | Update your runtime and package manager before cloning |
| Losing track of generated files | Set an output folder you will actually remember |
| Testing on a huge, complex prompt immediately | Start with a simple subject and add one variable at a time |
| Reporting a bug with no reproduction steps | Record your OS, build, and exact sequence first |

One more habit worth building: keep your own notes. When a prompt structure or reference combination produces something good, write down what you did. Open-source creative tools reward curiosity, and a personal log is how that curiosity compounds into a recognizable style instead of a folder of lucky accidents.

The app focuses on AI image generation and video, including animation that extends still images into motion. With reference-driven prompting and fine-grained prompt control, it suits concept art, storyboards, style exploration, and short motion tests.
